# Fix two UI issues: invisible badge text and overlapping notification FAB

## Context
Two CSS issues need fixing in the Tourism MVC project.

## Issue 1 — Invisible "Novice Explorer" badge text (site.css)
- **Root cause**: `.tourist-level-badge` uses `color: var(--text-heading);` which resolves to `#1E120A` (dark brown) in light mode. The badge renders inside `.navbar-utility` whose `background-color` is also `var(--bg-navbar-solid)` = `#1E120A`, making the text invisible.
- **File**: `Tourist_Project_MVC/wwwroot/css/site.css`
- **Location**: Immediately after the `.tourist-level-badge { … }` block (currently ends at line 660).
- **Change**: Add a new rule:
  ```css
  .navbar-utility .tourist-level-badge {
      color: #ffffff;
  }
  ```
- **Scope**: Only affects light mode on the utility navbar. Dark mode is untouched.

## Issue 2 — Notification FAB overlaps AI chat FAB (aiChat.css)
- **Root cause**: The notification FAB and AI chat FAB are positioned with `position: fixed` using `bottom` offsets that are too close together. Additionally, another rule may be overriding the `right` property so the notification FAB renders to the left of the AI FAB.
- **File**: `Tourist_Project_MVC/wwwroot/css/aiChat.css`
- **Changes** (5 edits total):

| # | Selector | Property | Old | New |
|---|----------|----------|-----|-----|
| 1 | `.notification-fab` (desktop) | `bottom` | `94px` | `130px` |
| 2 | `.notification-widget-panel` (desktop) | `bottom` | `166px` | `202px` |
| 3 | `.notification-widget-panel` (mobile `@media (max-width: 575.98px)`) | `bottom` | `144px` | `176px` |
| 4 | `.notification-fab` (mobile `@media (max-width: 575.98px)`) | `bottom` | `78px` | `110px` |
| 5 | `.notification-fab` (desktop, inside `/* NOTIFICATION WIDGET */` section) | `right` | `24px` | `24px !important` |

> **Note on edit #5**: After edits #1–4 are applied (which set `right: 24px` on both desktop selectors), the notification FAB may still render slightly to the left of the AI FAB due to a competing `right` rule elsewhere. Adding `!important` to the desktop `.notification-fab` `right` property forces alignment with `.ai-fab`'s `right: 24px`.

> **Note on `bottom` values**: The user referenced `bottom: 94px` as an identifier for the desktop `.notification-fab` rule, but the value has already been changed to `130px` per edit #1. The `right: 24px !important` edit applies to that same rule regardless of `bottom` value.
