# Creating & Managing Rewards

**SponsorRewardController** lets sponsors design reward offers and control where tourists can redeem them.

## Creating a reward

1. Open **Rewards** from the sponsor navbar.
2. Click **Create** and set the title, description, points cost or QR value, validity window, and branch assignment.
3. Save the reward. It becomes visible to tourists in the **Rewards** page.

## Assigning branches

- A reward can be tied to one or more branches.
- Tourist redemption is restricted to assigned branches only.
- Update assignments anytime from the reward edit form.

## Visibility and expiry

- Publish or unpublish rewards to control when tourists can see them.
- Expired rewards automatically hide from the tourist view but remain visible in the sponsor history.
- Set future start dates if you want a reward to appear later.

> **Tip:** Clear descriptions and realistic validity dates reduce confusion and support tickets from tourists who cannot redeem.
