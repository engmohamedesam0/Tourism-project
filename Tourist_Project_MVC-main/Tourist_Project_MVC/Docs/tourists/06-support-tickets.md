# Support Tickets

If you run into account issues, buggy behavior, or need help with rewards or trips, the **TouristSupportController** lets you open a tracked support ticket directly from your account.

## Submitting a ticket

1. Open **Support** from the account dropdown in the top bar.
2. Choose a category (Account, Rewards, Trips, Technical, Other).
3. Describe your issue in as much detail as possible.
4. Attach screenshots or files if they help explain the problem.
5. Submit and note the ticket ID for follow-up.

## Tracking updates

- Support replies appear in the support ticket listing with timestamps.
- You receive a notification in the site’s notification panel when an Admin or Sponsor updates your ticket.
- Ticket history is preserved so you can refer back to earlier resolutions.

## Best practices

- Check existing documentation or try the **AI Assistant** before opening a ticket to save time.
- Include steps to reproduce the issue, device type, and browser information for technical reports.
- One issue per ticket makes it easier for the support team to resolve quickly.

> **Warning:** Do not share passwords, credit card numbers, or identity documents in ticket attachments. Support will never ask you for confidential credentials over chat.
