# Common Tasks

This page collects the everyday Admin actions in short, repeatable steps. Bookmark it — most of your daily work is covered here.

## Adding a destination

1. Open the **Admin Dashboard** and click **Add Destination**.
2. Enter the name, Arabic name (optional), city, and category.
3. Add the description, tags, and ticket details (prices are cleared automatically for **Public** categories).
4. Add images — upload files or paste external URLs.
5. Select the location on the map (required).
6. Submit — the destination is created in ArcGIS, then synced to the website.

## Editing a destination

1. Open the **Destinations** page.
2. Click **Edit** on the destination.
3. Update the fields you need — including latitude/longitude for the map position.
4. Save — changes are pushed to ArcGIS first, then to the database.
5. Check the Explore page to confirm the updated information displays correctly.

## Deleting a destination

1. Open the **Destinations** page.
2. Click **Delete** on the destination.
3. Review the warning — missions and trip stops tied to it will be removed.
4. Confirm. ArcGIS removal happens first; only then is the database record deleted.

## Adding a mission

1. Open the **Missions** page and click **Create**.
2. Enter the title and description.
3. Choose the mission type and set the **points reward**.
4. Select the destination the mission is attached to.
5. Save — the mission goes live for tourists immediately.

## Creating a reward

1. Open the **Rewards** page and click **Create**.
2. Enter the title, type (Discount, Voucher, Gift, ...), and description.
3. Set the **points required** and **quantity available**.
4. Pick the **expiration date** and the **sponsor** offering it.
5. Save — the reward appears in the tourist Rewards catalog.

## Managing a badge

Badges are awarded **automatically** by the gamification engine — there is no badge editor. To influence them:

1. Review your **Missions** — points rewards drive progress.
2. Balance **Rewards** pricing so points stay valuable.
3. Watch tourist levels on profiles; they reflect badge progress.

## Managing a sponsor

1. Open the **Sponsors** page.
2. Approve new businesses from the **Approvals** page.
3. Edit registry details (name, type, city, contact) with **Edit** on the sponsor row.
4. Track their rewards from the **Rewards** page and their redemptions from the overview statistics.

## Reviewing a tourist

1. Open the **Tourists** page.
2. Search by name, email, or nationality.
3. Open the tourist's **Details** page to see their profile and platform activity (trips, favorites, mission progress).
4. Edit their profile information if anything is incorrect.

## Responding to a support request

1. Open **Support Inbox** from the **Sponsors** menu.
2. Click the ticket to see the full request.
3. Write your response and submit it.
4. Mark the ticket **Resolved** once the issue is closed — the submitter is notified at each step.

## Updating website content

1. Choose the content area: **Destinations**, **Trip Plans**, **Missions**, **Rewards**, **Sponsors**, or **Utilities**.
2. Open the relevant page, find the record, and click **Edit**.
3. Change the fields and save — the update goes live for tourists right away.
4. For destinations and map data, run **Sync to ArcGIS** from the **Admin Dashboard** afterwards to keep the map aligned.

> **Tip:** When in doubt, the AI assistant can perform most of these actions for you in plain language — it always asks for confirmation before making changes.
